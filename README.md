# Crypto Empire — نمونهٔ اولیهٔ مینی‌اپ تلگرام

یک بازی قابل‌بازی با ظاهر مشکی/نئونی و رابط فارسی: کلیک برای گرفتن سکه، چهار ساختمان قابل ارتقا، درآمد خودکار، سطح امپراتوری و ذخیره‌سازی محلی.

## آزمایش فوری
فایل `index.html` را در مرورگر جدید باز کن. بازی بدون نصب پکیج اجرا می‌شود. اسکریپت تلگرام اختیاری است.

## انتشار به‌عنوان Telegram Mini App
1. فایل `index.html` را روی میزبان HTTPS مثل GitHub Pages، Cloudflare Pages یا Netlify بارگذاری کن.
2. در تلگرام `@BotFather` را باز کن و با `/newbot` یک ربات بساز.
3. در BotFather گزینهٔ تنظیم Mini App یا Web App را پیدا کن و آدرس HTTPS را ثبت کن؛ برای دکمهٔ منوی ربات می‌توان از `/setmenubutton` استفاده کرد.
4. لینک ربات را در تلگرام باز کن و روی موبایل آزمایش کن.

## پیش از انتشار عمومی
این فقط نمونهٔ اولیهٔ سمت کاربر است؛ داده‌ها در localStorage ذخیره می‌شوند و قابل دستکاری‌اند. برای استفاده عمومی باید backend و پایگاه داده، اعتبارسنجی server-side دادهٔ `initData` تلگرام، محدودیت درخواست و ضدتقلب اضافه شود. سکه‌ها در این نسخه امتیاز مجازی‌اند و ارزش پولی ندارند. قرارداد توکن بلاک‌چینی هنوز ساخته یا منتشر نشده است.
